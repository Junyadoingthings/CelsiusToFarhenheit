# Celsius to Fahrenheit Converter  A Java console application that converts Celsius to Fahrenheit.  ## Features - Multithreading (InputThread + FileThread) - File I/O (saves conversions to temperatures.txt) - SQLite database via JDBC - Custom exception handling  ## Built With - Java - SQLite - JDBC  ## Author Junya — @junyadoingthings
